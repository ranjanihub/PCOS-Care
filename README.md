# PCOS Care

## 🩺 About PCOS Care
PCOS Care is a web application designed to spread awareness about **Polycystic Ovary Syndrome (PCOS)**. It allows users to **log in and test** whether they might have PCOS and, if diagnosed, provides personalized **recommendations** for lifestyle changes, diet, and workouts to improve their health.

🔗 **Live Website**: [PCOS Care](https://scintillating-kulfi-735837.netlify.app/)

## ✨ Features
- **PCOS Awareness**: Educates users about PCOS, symptoms, causes, and prevention.
- **PCOS Test**: Allows users to take a test to check if they have PCOS symptoms.
- **Personalized Recommendations**: Suggests lifestyle changes, diet plans, and workouts based on test results.
- **User Authentication**: Login and manage personal health data securely.
- **Responsive Design**: Fully functional across devices (mobile, tablet, and desktop).

   ```sh
   git clone https://github.com/your-username/PCOS-Care.git
   cd PCOS-Care
   ```
2. **Install dependencies**
   ```sh
   npm install
   ```
3. **Run the project**
   ```sh
   npm start
   ```
4. Open `http://localhost:3000/` in your browser.
